# 🎒 מוכנים לכיתה א'!

אפליקציית למידה אינטראקטיבית לילדים לפני כיתה א' — עם הקראה בקול בעברית.

## מה יש באפליקציה?

| מדור | תוכן |
|------|------|
| 🔢 חשבון | חיבור, חיסור, וספירה עם חידונים |
| 📖 קריאה | כל אותיות הא"ב, תרגול כתיבה עם מקלדת, וחידון אותיות |
| 🌍 עולם | יבשות, מדינות, בירות — וחידון |

**כל השאלות והתשובות מוקראות בקול בעברית** 🔊

## הרצה מקומית

פשוט פתחו את `index.html` בדפדפן — לא צריך שרת!

```bash
open index.html
```

## פריסה ב-GitHub Pages (בחינם)

1. צרו repository חדש ב-GitHub (לחצו על **New repository**)
2. העלו את קובץ `index.html`
3. לכו ל-**Settings → Pages**
4. תחת **Source** בחרו `Deploy from a branch` → `main` → `/ (root)`
5. לחצו Save — תוך דקה תקבלו לינק!

הלינק יראה כך:
```
https://YOUR-USERNAME.github.io/REPO-NAME/
```
